# Abdoul Salma — Portfolio

Personal portfolio for Abdoul Salma, a Computer Science student at the University of Ontario Institute of Technology. The site is a single static page: no build step and no dependencies beyond the browser.

## View it

Open `index.html` in a browser.

To serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://127.0.0.1:8000`.

## Sections

- **Home** — introduction, resume, and headshot
- **Projects** — QuestLog and CashFlow, with links to more work on GitHub
- **Skills & Tech** — languages, tools, libraries, and concepts
- **Education** — degree and relevant coursework
- **About** — short bio
- **Contact** — email, GitHub, LinkedIn, and resume
